AutoScene 0.2 is a rebuild from the ground up. It's a single native app for
Windows, macOS and Linux with no Python to install: FFmpeg and ONNX Runtime
ship inside it, and the AI models download on first use.

## What's new

- **Frame-exact media engine.** Each frame is indexed from the decoder, and
  each export is checked against the source frames. Interlaced sources are
  deinterlaced before the cut.
- **Analysis engine.** Shot detection with TransNetV2, then face detection,
  tracking and recognition (SCRFD and ArcFace). It runs on DirectML on
  Windows, Core ML on macOS and the CPU on Linux, and it picks up where it
  left off after a crash or a restart.
- **The cast.** Characters are found automatically in live action. You name,
  merge and split them, and you review the faces the analysis wasn't sure
  about with one key each. Every decision survives a new analysis and is
  applied to similar faces at once.
- **Scenepack builder.** For a character you get their shots with filters, add
  your own picks, preview the pack, and export it in one go. File names come
  from a template.
- **The player.** It keeps frame accuracy at every speed, with J/K/L shuttle
  (also backwards) and a zoomable timeline with shots and character lanes.
- **A new look.** The Cinematic redesign: big artwork, character portraits,
  native window materials (Mica on Windows 11, vibrancy on macOS) and a
  command palette (Ctrl/⌘ + K) that also finds characters and episodes.
- **Moved files are found again.** Point AutoScene at a folder and it relinks
  the episodes. Your analysis is kept when the file is the same video.

## Before you install

- **Not signed by a publisher yet.** On Windows, SmartScreen asks first:
  choose **More info → Run anyway**. On macOS, right-click the app and choose
  **Open**, or run `xattr -dr com.apple.quarantine /Applications/AutoScene.app`.
- **Anime:** shots and exports work. Characters in anime come in a later
  version.
- **Projects from 0.1 aren't carried over.** 0.2 keeps its own library, so add
  your episodes again.
- **The face models** come from InsightFace and may only be used
  non-commercially.
