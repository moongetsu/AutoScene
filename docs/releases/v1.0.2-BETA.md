AutoScene 1.0.2 Beta gives every person one entry in the cast, menus of its
own everywhere, and installers in AutoScene's look. Every download can now be
checked against the workflow that built it.

## What's new

- **One person, one character.** A reflection in a mirror, a face the
  tracker found twice, or someone standing in front of the cover picture no
  longer splits a person into two characters. On its first start this
  version groups your cast again, once (**Grouping characters** in the
  activity list). Names, characters you made and your decisions stay. When
  two characters turn out to be one person, the scenepack's filters and
  picked shots move to the one that remains. Twins and look-alikes who are
  often on screen together stay two.
- **The app's own menus and tooltips.** A right-click offers what the place
  under the pointer can do, on every screen down to the frame under the
  timeline's pointer. Text fields have their own menu, tooltips are glass
  ones, and the browser's leftovers are gone (find bar, print, link drags).
- **Big scenepacks stay quick.** In a pack of 6,000 shots, a click that
  picks or drops a shot takes about a third of the time and moves a
  twentieth of the data, and an export starts at once instead of after a
  minute. **Best first** now orders shots with the same score by their time
  on screen, then by the size of the face.
- **Installers in AutoScene's look.** On Windows, the installer's welcome
  and finish pages are dark with the gold mark. On macOS, the disk image
  opens on a window with an arrow to Applications, and the app has an icon
  on Apple's grid. Linux menus and docks get a sharp 512 px icon.
- **Smaller downloads.** The installers no longer carry a developer tool
  (17 MB). Updating on Windows also removes the copy older versions left
  behind.
- **Check your download** (see below): each file comes with a signed build
  attestation and is listed in `SHA256SUMS`. The macOS app is signed ad hoc
  now, so macOS no longer calls a download "damaged".

## Before you install

- **Already installed?** The app updates itself (**Settings → Updates**).
  Your projects and models are kept.
- **Projects move to a newer format.** Once a project is open in 1.0.2,
  older versions can't open it anymore.
- **Not signed by a publisher yet,** so the first start needs your OK once.
  On Windows, SmartScreen asks first: choose **More info → Run anyway** (with
  Smart App Control on, Windows 11 blocks the installer without that choice).
  On macOS, drag AutoScene to Applications, open it and close the message
  that macOS can't verify it. Then open **System Settings → Privacy &
  Security**, scroll down to the note about AutoScene, choose **Open Anyway**
  and confirm. (Since macOS 15, right-click → Open no longer does this.) If
  macOS later refuses a part of the app, such as `libonnxruntime.dylib`, run
  `xattr -dr com.apple.quarantine /Applications/AutoScene.app` once.

## Check your download

Each file comes with a signed record (a build attestation) of the workflow
of [tcmmi/AutoScene](https://github.com/tcmmi/AutoScene) that built it, and
the tag and commit it was built from. To check one, use the
[GitHub CLI](https://cli.github.com), signed in with any GitHub account:

```bash
gh attestation verify AutoScene_1.0.2-BETA_x64-setup.exe -R tcmmi/AutoScene
```

To insist on this tag and the release workflow, add
`--source-ref refs/tags/v1.0.2-BETA --signer-workflow tcmmi/AutoScene/.github/workflows/release.yml`.

Or compare SHA-256 hashes: put `SHA256SUMS` next to your downloads and run
`sha256sum --check --ignore-missing SHA256SUMS` (Linux) or
`shasum -a 256 --check --ignore-missing SHA256SUMS` (macOS). In PowerShell
on Windows, this prints `True` for an intact download:

```powershell
(Get-FileHash .\AutoScene_1.0.2-BETA_x64-setup.exe).Hash -eq (-split (Select-String -Path SHA256SUMS -Pattern x64-setup.exe -SimpleMatch).Line)[0]
```
